How a result gets here

Every score on this dashboard traces back through five deterministic-then-generative steps.

1Retrieve — hybrid dense + keyword search over resume chunks
2Rerank — cross-encoder rescoring of the shortlist
3Rule engine — deterministic PASS/FAIL + weighted score, no LLM involved
4Evidence — resume snippets backing each matched skill
5Explain — LLM restricted to the evidence above, never overrides the decision
